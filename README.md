# Portfolio Source Code

This repository contains the source code for my personal portfolio website.

## Development Stack

- PHP
- Laravel
- JavaScript
- Bootstrap
- Tailwind CSS
- MySQL / MariaDB
- Git & GitHub
- GitHub Actions CI

## Continuous Integration

GitHub Actions validates the portfolio on pushes to `develop` and `master`, and on pull requests targeting `master`. The workflow checks required site files, parses the HTML, verifies required sections, and checks local asset references without requiring Node.js.
